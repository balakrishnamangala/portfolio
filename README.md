# Portfolio — Balakrishna Mangala

A modern, Apple-inspired portfolio built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, **Three.js**, and **Framer Motion**.

## Features

- **Three.js** 3D particle network background with mouse-reactive camera
- **Framer Motion** scroll-driven animations and section transitions
- **3D tilt cards** with perspective transforms on hover
- **Custom cursor** with magnetic hover effects
- **Animated counters** that count up on scroll into view
- **Skills pills** with staggered entrance animations
- **Apple-style** black and white minimal design
- **Fully responsive** — works on mobile, tablet, and desktop

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Three.js / @react-three/fiber
- Framer Motion
- GSAP (ScrollTrigger)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

1. Push to GitHub
2. Import repo on [vercel.com](https://vercel.com)
3. Deploy — no configuration needed
